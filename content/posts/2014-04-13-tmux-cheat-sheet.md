## Default keybinds

- `Ctrl+b` — Default prefix
- `Prefix+c` — Create window
- `Prefix+n` — Next window
- `Prefix+p` — Previous window
- `Prefix+%` — Split horizontal
- `Prefix+"` — Split vertical
- `Prefix+z` — Zoom in/out pane
- `Prefix+x` — Close pane
- `Prefix+w` — Preview session
